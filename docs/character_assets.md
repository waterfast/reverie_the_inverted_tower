# 猫雷角色素材与导入

## 当前版本

采用猫雷初始女仆装作为参考：青绿色双辫、小恶魔角、女仆头饰、紫色配饰、
深色上衣、白色围裙、青色裙子和橙色蝴蝶结。
生成方式为内置 imagegen，提示词保存在 `character_generation_prompt.md`。
这是同人 Demo 素材，不代表官方授权，公开参考来源见 `asset_sources.md`。

生成图的细节密度高于小角色能表现的范围，因此游戏采用 24x24 像素版本。
原图保留，后续仍可手工修整细小五官和帧间一致性。

## 动作顺序

| 图集帧号 | 内容 | 当前用途 |
| --- | --- | --- |
| 0–1 | 待机 | 站立循环 |
| 2–5 | 跑步 | 左右移动循环 |
| 6–7 | 起跳、上升 | 离开支撑面 |
| 8–9 | 下落 | 朝重力方向下落 |
| 10–11 | 翻转施法 | 转换器切换世界时的施法表现 |
| 12–13 | 电击攻击 | X 电击攻击，判定由 combat.lua 负责 |
| 14–15 | 受伤 | 受伤和死亡动作，combat.lua 控制 |

全部图片朝右，朝左和倒立通过 spr 的水平/垂直翻转参数实现。
暂停菜单选择 sprite gallery 查看全部 16 帧，再按 Z/X 回到游戏。

## 文件说明

- `nyaru_actions_source_v1.png`：透明生成原图，作为源素材保留。
- `nyaru_actions_24.png`：96x96 透明动作图，四行四列，每帧 24x24。
- `nyaru_actions_preview.png`：最近邻放大预览。
- `nyaru_pico8_sheet.png`：128x128 完整精灵表，与当前卡带一致。
- `nyaru_frames.json`：帧号和 PICO-8 精灵编号对照。

黑色（0 号色）表示透明，角色轮廓使用深蓝。
角色图集放在精灵表 x=8..103、y=0..95，原有左上角小图保留。
这里使用了部分精灵表下半区，和扩展地图行 32..63 共用内存。
当前关卡用代码定义平台；今后使用地图编辑器时，先使用地图行 0..31。

## 已完成的导入

`tools/import_character.py` 已转换尺寸、调色板和卡带 __gfx__ 数据，
写入主卡带。现在不必再手动导入，重新 load 主卡带就能看到角色。
生成原图保持不变，导入脚本只做确定性的数据转换。

## 以后手动导入

先保存和备份卡带，再加载项目，在 PICO-8 控制台输入：

```text
import assets/sprites/nyaru_pico8_sheet.png
```

检查精灵编辑器，按 Ctrl+S 保存，Ctrl+R 运行。
这个命令替换整张精灵表；已有新素材时不要再导入旧完整表。
只替换角色区域用：

```text
import assets/sprites/nyaru_actions_24.png -x 8 -y 0
```

也可以在精灵编辑器选中编号 1 的小格，再拖入动作 PNG。
不要直接导入高分辨率生成原图，先转换成游戏所用的尺寸。

## 外部重建

开发电脑需要 Python 和 Pillow。在项目根目录运行：

```text
python tools/import_character.py
```

这会更新角色图、编号表、完整精灵表和卡带中的角色区域。
运行前保存 PICO-8 内的修改，运行后重新 load，避免旧编辑器覆盖外部更新。
