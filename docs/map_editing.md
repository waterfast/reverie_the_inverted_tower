# PICO-8 地图编辑：把地图当作房间素材仓库

## 地图不是无限世界

精灵编辑器画 8x8 小砖，地图编辑器铺这些砖。
卡带有 128x32 格独立地图区，可以像拼图一样切成多个房间。
游戏进入一间房时，只读取该房间对应的矩形；门的配置决定它通向哪里。
这些矩形在编辑器里的相邻关系，不等于游戏里的连接关系。

## 当前分区

| 房间 | 地图编辑器坐标（格） | 实际大小（像素） |
| --- | --- | --- |
| 初始时钟塔 | x=0..63，y=0..31 | 512x256 |
| 月影回廊 | x=64..95，y=0..15 | 256x128 |
| 封印书库 | x=96..127，y=0..15 | 256x128 |
| 无声钟室 | x=64..95，y=16..31 | 256x128 |
| 空白保留区 | x=96..127，y=16..31 | 可再容纳一间小房间 |

表城与逆城共用这些格子。编辑表城地形时，逆城也会使用修改后的地形。
逆城保留格子位置和砖图案，只把角色、小怪重力反过来。
地图行 32..63 和精灵表下半区共用内存，当前那里有角色图，不要作为新房间使用。

## 怎么画

1. 重新 load 主卡带，按 Esc 打开编辑器，进入地图页。
2. 在下方选素材，点击或拖动铺格子。
3. 按住空格拖动画布，滚轮缩放，找到表中的房间区域。
4. Ctrl+S 保存，Ctrl+R 运行。

正常游戏不会重新写入地图；编辑结果直接生效。
seed_map.py 和 add_rooms.py 是初次建图工具，不在运行时使用，也会拒绝覆盖已有地图。

## 门和机关在哪里编辑

门的位置不从地图里猜测，集中配置在 src/rooms.lua。
每扇门有 x/y/w/h、target（目标房间）、entry（目标入口名字）。
这些 x/y 是所在房间的像素坐标，独立于素材仓库坐标。
只编辑 normal，reverse 共用同一对象。门洞和入口不能按重力分成两套。
在地图里修改门附近时，保留支撑地板和角色站立空间。

## 做正式路线前

当前角色碰撞盒为 8x18 像素，跳跃最高约 26 像素。
先把可直接跳上的台阶高度控制在 24 像素内，再检查水平距离和头顶空间。
正常和逆重力都需要测试；共用地形不意味着两边所有路线天然可达。
本次验证了入口不穿墙和通道连接；翻转后的完整可达性仍待关卡设计和试玩。

修改 config.lua 只影响控制和视口等参数；修改 rooms.lua 的 columns/rows
才会改变对应房间的边界，编辑地图时不要超出它声明的范围。
更新角色图时用局部图集导入，不要导入修改前的完整精灵表覆盖新地图素材。

## 本次原型的地形覆盖

墙洞和高处测试台阶定义在 src/rooms.lua，运行时由 room_tile 同时用于绘制和碰撞，
不会写回地图编辑器。回廊和钟室还有 clear_areas，清出测试跳跃所需的头顶空间。
如果修改的地图砖没有在游戏出现，先检查是否落在这些覆盖范围；正式关卡时删改
对应 platforms/clear_areas 即可。这些覆盖也是正逆重力共用的一份。
